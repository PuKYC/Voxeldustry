已解除 / 已接受（2026-10-20，2026-10-22 增量）：

- **Android 已能稳定运行**：不再按“实验性平台”计；`release.yml` 两个 Android leg 已改为 `experimental: false`，失败会阻断发布（见 [[09-构建测试与CI]]）。
- **载荷 code 7 留空不构成风险**：线格式上 code 7 仍不复用、新载荷只在末尾追加，但单人维护阶段不再作为待办（见 [[05-表现管线]]）。
- **接缝台阶墙：接受，不再列为风险**。台阶只出现在远处 LOD 交界，实际观感无关紧要；LOD fade 与各向异性 LOD 不再单独排期，日后真要打磨再拿出来。
- **`docs/ci.md` 已按当前 workflow 校对**（2026-10-20）：job 结构、runner 镜像、Android SDK/NDK 版本、experimental 状态全部对齐。
- **交互提示缺 ActionId 反查已解决（2026-10-22，P3b）**：键鼠提示改为从 InputMap 该动作绑定的第一个键鼠事件取键名（键盘 `OS.get_keycode_string(physical_keycode)`、鼠标 `as_text()`），触屏显示 `Tap`，不再硬编码「按 E」（见 [[10-Godot-UI方案]]）。
- **原生 Button 触摸 / 多指能力已实证（2026-10-22，verifier）**：Godot 4.7.2 上 ScreenTouch 直接触发原生 Button，多指各按各的；「必须在自绘控件里绕开 Button」的旧假设不成立。自绘 `ActionButton` 改为按「释放时机 / per-index 语义 / HudWidget 契约」三条理由解释（见 [[10-Godot-UI方案]]）。
