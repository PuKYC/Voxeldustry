## 技术债与风险

| 项 | 影响 | 处理 |
| --- | --- | --- |
| 载荷 code 7 永久留空 | 线格式约束，复用会破坏 Godot ABI | 保持留空，新载荷只在末尾追加 |
| 接缝是台阶墙 | 远处 LOD 交界可见台阶 | 用 LOD fade 或各向异性 LOD，不依赖裙边 |
| 裙边在当前路径下是 no-op | 正确性安全网，但不解决观感 | 保留并回归测试，改动 extract 路径时重新评估 |
| `crates/chunky-bevy` 未接入 workspace | 游离代码容易被误认为在用 | 接入或移出，二选一 |
| clippy 非阻塞 | 代码质量门禁形同虚设 | 清完 warning 后去掉 `continue-on-error` |
| 指令数门禁非阻塞 | 指令级回归暂时只能观察 | 数字稳定后转为阻塞 |
| Android 实验性 | 发布矩阵不保证 | 跑稳后改为强门禁 |
| Windows MinGW 与 macOS 覆盖不足 | 平台风险 | 按需切换 MSVC 或补 macOS 预设 |
| 仓库缺 README | 新读者只能从代码与 `docs/` 进入 | 用本板块作为入口，或补根目录 README |
| `docs/ci.md` 与 `ci.yml` 的 runner 镜像不一致 | 文档描述与实际流水线不符 | 二选一改齐：文档改 runner，或 workflow 升到 24.04 |
| 预测只做本地历史采样 | 没有重演与纠偏 | 局域网期次补 reconciliation |

## 维护这份板块的规则

- 架构变化时改对应笔记，并在本笔记更新状态表。
- 新增载荷、新增阶段、改线格式，必须同步改 [[05-表现管线]] 与契约测试。
- 新增平台或改性能阈值，必须同步改 [[09-构建测试与CI]]。
