# 网络、隐私、预测与回滚

## 当前形态

| 模式 | 状态 |
| --- | --- |
| 单人 | 已实现。本地权威直跑，无网络 |
| 局域网 | 规划中。权威服务器加客户端预测副本，复用同一套系统 |
| 网络适配 | `net` feature，默认关闭，依赖 bevy_replicon 0.43 与 bevy_replicon_renet 0.19 |

单人构建不编译 replicon，依赖树保持干净。

## 感知掩码

- `PerceptionMask(u32)` 是观察者的感知位掩码，位义由游戏定义：己方阵营、同公会、看穿隐身。
- `perception_allows` 是唯一真值函数，网络路径与单人内存直通路径都调用它，避免联机隐身而单机全透明的分裂。
- `RequiredPerception<S>` 是泛型可见性需求组件；`impl VisibilityFilter` 只在 `net` feature 下存在。
- `memory_path_component_visible` 是单人直通版本的同一真值。
- `define_privacy_components!` 由业务层一次性声明哪些组件是隐私组件。

## 隐私组件

- 隐私载荷在载荷表里用 `private: ExactHealth` 声明，收集时按可见性门控。
- 具体隐私组件在 `game-core/src/privacy.rs`，配有 `CorePrivacyScope`。
- 调试构建有 `VisibilityViolations` 自检：把隐私组件发给不该看到的观察者会记录违规。
- 表现层只发可见实体的载荷，`PresentationVisibility` 同时供 AOI 与隐私门控使用。

## 预测与回滚

分层：机制在 `game-engine::rollback`，状态与策略在 `game-core::prediction`。

| 概念 | 类型 | 说明 |
| --- | --- | --- |
| 预测标记 | `Predicted` | 参与预测与回滚的组件。纯表现副作用不挂，避免重演时重复触发 |
| 回滚基线 | `Snapshot` | 位置、速度、yaw |
| 状态推进 | `apply_input` / `resimulate` | 纯函数，可脱离 Bevy 单测 |
| 历史 | `StateHistory<S>` | 按 tick 的环形缓冲，可截断回滚 |
| 渲染策略 | `RenderPolicy` | 按预测采样或按固定延迟插值 |
| 采样 | `sample_render_states` | 从历史取两端点写 `PresentedTransform` |
| 回滚时钟 | `RollbackState` / `RenderHistory` | 引擎侧通用机制 |

单人路径：全部实体 `Predicted`、延迟 0、无重演。`record_local_history` 每 tick 写历史，采样器读历史而不是瞬时值，等待回滚重写时不被污染。

## 为什么副作用不挂 Predicted

受击震屏、粒子、音效这类纯表现副作用如果参与重演，回滚会重复触发，例如死亡音效播两次。所以 `Predicted` 只挂逻辑状态组件。
